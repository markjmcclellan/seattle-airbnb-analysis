About this project

This was originally a Python data visualization assignment. I cleaned the data, explored pricing differences, and tested a linear regression model. This site presents a short summary of that analysis.

Data & limitations

The data comes from a historical Seattle Airbnb listings dataset. Missing satisfaction ratings were kept for the price charts but excluded from the regression. These are advertised nightly prices, not booking totals or current prices.

Dataset: Seattle Airbnb Listings on Kaggle (uploaded by Shane Lev).
